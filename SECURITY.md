# Safety and privacy

Use fictional data only. DemoMed, the sensitivity flag and report content are simulated. The workspace provides no clinical advice or verified credentials.

The app stores the fictional case in this browser's local storage. Demo role switches and the caregiver preview demonstrate workflow visibility. They provide no authentication or server-side access control. A QR encodes an opaque token and verification compares it with the local demo record. Reset demo clears this origin's case.

RxEase provides editable fields for typing or dictation from the installed Wispr Flow client. RxEase does not call a Wispr API or perform speech recognition. The built-in example inserts labeled simulated text. Installed dictation software may process speech externally. Mixed-language text is stored as entered and the quantity prompt flags selected ambiguous patterns for manual review.

Report an issue in this hackathon repository with fictional examples only.
